# Site vitrine — Thomas, graphiste freelance

Site portfolio responsive réalisé dans le cadre d’un exercice d’intégration HTML/CSS. Il présente les services de Thomas en identité visuelle, UI et illustration.

## Fonctionnalités

- Navigation fixe avec des liens vers les sections du site
- Mise en page responsive : ordinateur, tablette et mobile
- Bouton de téléchargement du CV au format PDF
- Images avec textes alternatifs
- Formulaire de contact accessible

## Technologies utilisées

- HTML5
- CSS3
- Police : Heebo

## Lancer le projet en local

1. Téléchargez ou clonez le dépôt.
2. Ouvrez le dossier du projet.
3. Ouvrez `index.html` dans un navigateur.
